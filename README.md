# Garry Botsparov

A Python chess engine project featuring move generation, board evaluation, search, and benchmarking against Stockfish.

## Features

- Legal move generation
- Position evaluation
- Minimax/negamax search
- Alpha-beta pruning
- Stockfish benchmarking
- Pygame-based interface

## Current status

Project is under active development. The engine can play complete games and is being improved with stronger search and evaluation features.

## Planned improvements

- Transposition table
- Move ordering
- Iterative deepening
- Quiescence search
- Improved evaluation function
- Opening book support
